# PARAMS

PARAMS извлекает значения, необходимые команде, из запроса пользователя. Он запускается
после того, как CASE распознаёт команду. Для запроса «покажи заказ 4815» CASE выбирает
команду заказа, а PARAMS возвращает номер заказа. Затем приложение может
открыть экран заказа, уже применив этот номер.

Команда предоставляет параметры, которые она принимает, и, если это уместно,
доступные значения, которые можно указать в тексте. PARAMS использует модель
GLiNER2 ONNX для поиска значений в запросе и сопоставления их с этими параметрами.
Этот же механизм обрабатывает как непосредственное значение, например номер заказа,
так и именованный вариант, например клиента, статус или элемент оборудования.

Вместе CASE и PARAMS преобразуют один запрос в команду и её аргументы.
Приложение получает обе части и выполняет обычную навигацию или действие.
