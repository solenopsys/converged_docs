# CASE

CASE интерпретирует запрос пользователя как команду платформы. Он получает набор
команд, которые может выполнять платформа, и примеры фраз, выражающих каждую
из них. Из фразы «покажи оборудование» он выбирает команду, открывающую список
оборудования. Из фразы «покажи заказ 4815» он выбирает команду, открывающую заказ.

Сервис сравнивает запрос с примерами команд и возвращает выбранную команду с
оценкой. `EXECUTE` означает, что одна команда распознана достаточно однозначно,
чтобы её выполнить. `AMBIGUOUS` означает, что несколько команд слишком похожи,
чтобы выбрать одну из них. `UNKNOWN` означает, что запрос не соответствует
набору команд.

CASE определяет, что пользователь хочет сделать. Он не извлекает детали этого
запроса. Когда команде нужны эти детали, PARAMS читает тот же текст и возвращает
значения, необходимые для открытия или фильтрации результата: в «покажи заказ
4815» CASE выбирает команду для заказа, а PARAMS извлекает `4815`.
