# lm-kubernetes

## Назначение

Мост оператора Kubernetes без сохранения состояния: применяет намерения автоматизации платформы к ресурсам кластера (развертывания, задания) через выделенный клиент. Без постоянного состояния; секреты разрешаются через lm-secrets.

## Граница ответственности

Отвечает за трансляцию API кластера и чтение операций применения/статуса; не отвечает за оркестрацию рабочих процессов, планирование или хранение секретов.
