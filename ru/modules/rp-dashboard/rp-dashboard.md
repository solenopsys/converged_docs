# rp-dashboard

## Назначение

Персональное хранилище закреплений дашборда: запоминает, какие виджеты индикаторов пользователь
закрепил, их порядок и метаданные отображения. Здесь не вычисляются метрики,
только расположение собственного экрана пользователя.

## Граница ответственности

Владеет строками закреплений (виджет, заголовок, источник, позиция) с видимостью для каждого пользователя;
не владеет метриками, счетчиками или отрисовкой виджетов.
