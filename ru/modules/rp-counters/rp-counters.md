# rp-counters

## Назначение

Конфигурация внешних счётчиков аналитики для каждого тенанта: хранит tracking ID (GA4, GTM, Яндекс Метрика, Meta Pixel) или пользовательский head-сниппет, чтобы SSR мог встраивать нужные скрипты для каждого тенанта.

## Ментальная модель

Оператор сохраняет счётчик (тип, tracking ID или сниппет, флаг включения) → хранилище сохраняет конфигурацию. SSR читает включённые счётчики для текущего тенанта и отображает соответствующие теги. Здесь не собираются числовые данные, только настройки счётчиков.

## Ценность для экосистемы

Единое место для подключения аналитики:

- Внешние счётчики (GA4, GTM, Метрика, Pixel) и пользовательские сниппеты настраиваются для каждого тенанта, а не прописываются жёстко для каждого лендинга.

## Не цели

- Не хранилище сырых событий.
- Не журналы числовых samples.
- Не записи использования или биллинг.
## Граница ответственности

Владеет конфигурациями счётчиков (тип, tracking ID или сниппет, флаг включения); не собирает метрики, не агрегирует использование и не занимается биллингом.
