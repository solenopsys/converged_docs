# rp-struct

## Назначение

Общий построитель структур: превращает свободный контент в типизированные представления, соответствующие схеме,
на которые может положиться каждый потребитель. Единая точка моделирования между исходным контентом
и отрисовкой каналов.

## Ментальная модель

Исходный контент на входе → моделирование структуры применяет схемы и формы → типизированные
блоки на выходе. Каналы (`sf-*`, markdown, шаблоны уведомлений) отрисовывают блоки
без повторного разбора источника.

## Ценность для экосистемы

Одна бестиповая полка JSON:

- Документы JSON за единым файловым API.
- Любой производитель хранит структурированные блобы без собственной обработки файлов.

## Нецели

- Не таксономия и не разметка.
- Не отрисовка markdown.
## Граница ответственности

Отвечает за моделирование структуры и формирование на уровне схемы; не отвечает за финальную
специфичную для каналов отрисовку.
