# rp-environment

## Назначение

Конфигурация среды для каждого пользователя: настройки и состояние рабочей области в пределах идентификатора. Потребляется поверхностями для персонализации без разветвления записей идентификаторов.

## Граница ответственности

Отвечает за CRUD конфигурации среды в пределах пользователей; не отвечает за жизненный цикл идентификаторов, проверку подлинности и разрешения.

- Нет
