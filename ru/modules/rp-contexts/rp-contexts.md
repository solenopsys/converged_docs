# rp-contexts

## Назначение

Общее хранилище именованных контекстов для ИИ: промпты, языковые варианты и
предметные знания находятся здесь, а не закодированы в каждом рабочем процессе.
Версионируется по имени, разрешается по языку.

## Ментальная модель

Рабочий процесс или ассистент запрашивает контекст по имени (+ язык) → получает
текущий текст. Редакторы обновляют контексты без повторного развертывания потребителей.
Хранение и получение находятся здесь; промпт-инженерия — у редакторов.

## Ценность для экосистемы

Одна полка знаний для ИИ-путей:

- Именованные контексты с языковыми вариантами за одним API.
- Любой ИИ-путь разрешается в тот же именованный контекст вместо собственных копий промптов.

## Нецели

- Не история чата и не диалоговые ветки.
- Не выполнение промптов — только сохраненные тексты контекстов.
## Граница ответственности

Отвечает за хранение и получение именованных контекстов ИИ и языковых вариантов;
не отвечает за инфраструктуру поставщика моделей и диалоговое поведение.
