# rp-classifier

## Назначение

Общий сервис разметки: любой сбор направляет сюда необработанный контент и получает
назад категории, метки или намерения. Одна логика классификации вместо
цепочек if для каждого домена.

## Ментальная модель

Производитель отправляет необработанные элементы (файлы, тексты, запросы) → классификатор присваивает
метки → вызывающая сторона маршрутизирует по метке (производственная модель vs чертеж, срочное
vs шум). Метки — это рекомендации; бизнес-решение остается за вызывающей стороной.

## Ценность для экосистемы

Единая полка таксономии:

- Узлы дерева и сопоставления ключей за одним API.
- Любой сбор разрешает метки из того же дерева вместо собственных словарей.

## Не цели

- Не байты файлов и не преобразование.
- Не хранение документов JSON.
## Граница ответственности

Отвечает за логику классификации и назначение меток; не отвечает за конвейеры приема исходного контента и последующую бизнес-маршрутизацию.

## Прямые зависимости модулей

- Нет

## Принадлежность к решению

- Не входит в предопределенное решение
