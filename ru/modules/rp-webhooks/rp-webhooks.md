# rp-webhooks

## Назначение

Единственная входная дверь для внешнего мира: внешние системы обращаются к одной
конечной точке вебхука, а этот модуль проверяет, нормализует и направляет события
внутрь. Ни один домен не раскрывает собственную схему URL обратного вызова.

## Ментальная модель

POST внешней системы → вебхук проверяет подпись и структуру → нормализованное
событие записывается как доставка и направляется в настроенный топик.
Попытки доставки и проверка находятся здесь; бизнес-реакция происходит
ниже по потоку.

## Ценность для экосистемы

Единый вход для внешних колбэков:

- Конфигурации конечных точек и записи о доставках за единым API.
- Любая внешняя система получает одинаковую форму конечной точки вместо отдельной инфраструктуры для каждой интеграции.

## Не цели

- Не выполнение рабочих процессов.
- Не публикация событий и не отправка уведомлений.
## Граница ответственности

Отвечает за транспорт webbхуков, проверку и попытки доставки; не отвечает
за бизнес-обработку целевой системы.

## Прямые зависимости модулей

- Нет

- Не входит в предопределенное решение
