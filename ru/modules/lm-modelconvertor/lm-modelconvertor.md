# lm-modelconvertor

## Назначение

Общий мост форматов моделей: преобразует продакшн-модели между внутренними и внешними представлениями (например, в GLB-превью), чтобы ни один рабочий процесс напрямую не подключал нативную библиотеку-конвертер.

## Ментальная модель

Рабочий процесс подготавливает байты модели → конвертер преобразует формат → возвращает байты превью/преобразованные байты как cache-refs для `rp-files.persist`. Чистое преобразование: без хранения, без оценок, без бизнес-решений.

## Ценность для экосистемы

Единая точка конвертации для продакшн-моделей:

- Подготовленный файл на входе, преобразованные выходные данные как cache-refs на выходе — одинаковая форма для любого вызывающего.
- Новые форматы и версии конвертера добавляются один раз и обновляют каждый путь анализа.
- Удерживает тяжелые нативные зависимости вне рабочих процессов и репозиториев.

## Нецели

- Не файловое хранилище и не оркестрация приема.
- Не рендеринг превью и не оценки нарезки.

## Граница ответственности

Владеет процедурами конвертации/трансформации; не владеет обучением моделей выше по потоку, обслуживанием ниже по потоку или персистентностью.

## Прямые зависимости модулей

- Нет

## Принадлежность к решению

- Не входит в предопределенное решение
