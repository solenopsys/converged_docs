# rp-sheduller

## Назначение

Общий триггер времени: расписания cron и история их выполнения для всей
экосистемы. Любая повторяющаяся задача регистрируется здесь вместо запуска
собственного цикла таймера.

## Ментальная модель

Оператор определяет запись cron (какой рабочий процесс, когда, с какими аргументами) →
среда выполнения срабатывает по расписанию → история фиксирует, что было запущено и как завершилось.
Этот модуль хранит и перечисляет записи; сам ничего не выполняет.

## Ценность для экосистемы

Единые часы для повторяющейся работы:

- Строки cron, история запусков и статистика за единым API.
- Любой повторяющейся задаче нужна только строка cron — без новой инфраструктуры таймеров.

## Не цели

- Не определение и не выполнение рабочих процессов.
- Не разовые триггеры — только повторяющиеся расписания.
## Граница ответственности

Отвечает за CRUD/список/статистику записей cron и записей истории; не выполняет
рабочие процессы, таймеры, повторы или фоновую рассылку.
