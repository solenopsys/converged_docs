# lm-push

## Назначение

Push-ветвь общего веера уведомлений: web/mobile push-транспорт за контрактом rp-notify.

## Ценность для экосистемы

Уведомления в реальном времени для чатов, заказов, запросов — доставляются вместе с email/SMS из единого намерения notify.

## Нецели

Без таргетинга и бизнес-логики — это относится к rp-notify и вызывающему домену.

## Граница ответственности

Отвечает за детали интеграции push-провайдера; не отвечает за бизнес-логику таргетинга уведомлений.

## Прямые зависимости модулей

- Нет

## Принадлежность к решениям

- Не входит в предопределенное решение
