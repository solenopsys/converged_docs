# rp-usage

## Назначение

Общий счётчик потребления: любая функция сообщает здесь, «сколько было использовано»,
вместо локального отслеживания квот. Агрегируется по потребителю и периоду —
источник, из которого читают биллинг и лимиты.

## Ментальная модель

Функция фиксирует потребление (кто, что, сколько, период) → использование
агрегирует его по аккаунту/периоду. Нижестоящий биллинг превращает агрегаты в деньги;
проверки лимитов читают текущие итоги. Измерение живёт здесь, ценообразование живёт
ниже по потоку.

## Ценность для экосистемы

Один журнал событий использования:

- Любая функция одинаково записывает строки (функция, пользователь, дата).
- Связки решение-функция позволяют любому отчёту группировать вызовы по решению без таблиц квот для каждого модуля.

## Не цели

- Не выставление счетов и не выполнение платежей.
- Не аутентификация и не проверки разрешений.
- Не сырые счётчики для дашбордов.
## Граница ответственности

Отвечает за измерение и агрегацию использования; не отвечает за выставление счетов, выполнение платежей
или ценовую политику.
