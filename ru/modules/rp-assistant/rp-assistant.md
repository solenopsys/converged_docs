# rp-assistant

## Назначение

Разговорный интерфейс ИИ для конечных пользователей и внутренних инструментов: обработка диалогов, прием запросов с учетом файлов и передача в аналитические рабочие процессы. Читает именованные промпты из rp-contexts и треды из rp-threads.

## Граница ответственности

Отвечает за диалоговое поведение ассистента и обработку запросов; не отвечает за инфраструктуру поставщика моделей, хранение тредов и идентификацию пользователей.
