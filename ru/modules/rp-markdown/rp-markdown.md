# rp-markdown

## Назначение

Общий Markdown-конвейер: разбор, преобразование и рендеринг для
каждого модуля, работающего с текстовым контентом. Одно поведение парсера вместо
вариантов для каждой поверхности.

## Ментальная модель

Исходный Markdown на входе → разбор/преобразование → отрендеренный вывод (HTML, блоки).
Авторы контента пишут один раз; документы, чаты, лендинги и уведомления рендерят
один и тот же исходник согласованно.

## Ценность для экосистемы

Единая текстовая основа:

- Markdown-файлы плюс JSON-конвертация за единым API.
- Любой продюсер хранит человеческий текст одинаково вместо собственной обработки файлов.

## Нецели

- Не типизированное блочное хранилище.
- Не HTML-рендеринг.
## Граница ответственности

Отвечает за поведение конвертации/разбора Markdown; не отвечает за транскодирование
мультимедиа или компоновку страниц.
