# Valkey

Valkey предоставляет Converged внутрипамятный сервис типа «ключ-значение». Он используется для
данных, которым полезны команды Valkey и семантика истечения срока действия: кэшированных значений,
счётчиков, краткоживущего состояния координации и других общих значений, которые необходимо
быстро читать или изменять.

Обёртка компилирует поставляемый вместе с ней сервер в нативную библиотеку и запускает его в
собственном потоке. Сервер прослушивает настроенные локальные адрес и порт;
затем обёртка взаимодействует с ним через libvalkey. Его C API запускает и останавливает
сервер, проверяет готовность, сообщает об использовании памяти и выполняет поддерживаемые
операции с ключами и значениями.

Эта встроенная конфигурация отключает снимки и AOF, использует одну логическую
базу данных и применяет политику вытеснения `allkeys-lru` в пределах настроенного
лимита памяти. Эти настройки делают жизненный цикл явным, вместо того чтобы наследовать
его от внешней установки Valkey.
