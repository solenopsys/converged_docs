# sqlite-vec

`sqlite-vec` добавляет векторные столбцы и запросы ближайших соседей в хранилища SQLite, используемые Converged. Векторная таблица может хранить эмбеддинги рядом с полями, идентифицирующими и описывающими исходный объект, поэтому запросу поиска не нужно покидать хранилище только для ранжирования похожих записей.

Расширение предоставляет виртуальные таблицы `vec0` для векторов с плавающей точкой, int8 и двоичных векторов. Запросы возвращают строки, упорядоченные по расстоянию; метаданные, вспомогательные столбцы и ключи секционирования остаются доступными в том же запросе SQLite. Это полезно для путей семантического поиска и извлечения данных платформы, где фильтрация и ранжирование выполняются в рамках одной операции.

Обёртка собирает вышестоящее расширение C как нативный артефакт. SQLite загружает его в процесс, владеющий базой данных; в этой интеграции нет отдельного сервиса векторного поиска.
