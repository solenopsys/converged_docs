# Stanchion

Stanchion добавляет в SQLite колоночные таблицы. Он используется, когда хранилищу Converged необходимо читать небольшой набор полей во множестве записей: измерения, историю событий, журналы и другие данные, ориентированные на добавление. Обычная таблица SQLite хранит строку целиком; таблица Stanchion хранит каждый столбец в отдельных сегментах, поэтому запрос читает только указанные в нём столбцы.

Stanchion доступен через интерфейс виртуальных таблиц SQLite. Таблица объявляется с помощью `USING stanchion` и `SORT KEY`; ключ сортировки определяет физический порядок записей и позволяет расширению пропускать группы строк, которые не могут соответствовать предикату. Значения буферизуются как ожидающие вставки, а затем записываются в сегменты столбцов с использованием кодировок, выбранных расширением.

Обёртка собирает расширение для нативной среды выполнения SQLite. Stanchion всё ещё находится на альфа-стадии: его дисковый формат и поддерживаемые операции с таблицами пока не зафиксированы.
