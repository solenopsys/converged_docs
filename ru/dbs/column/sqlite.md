# SQLite

SQLite — это реляционный движок хранения, лежащий в основе нативных обёрток базы данных.
Он хранит базу данных в локальном файле и выполняет SQL в вызывающем процессе, благодаря чему
сервис Converged может держать свои записи, индексы и транзакции рядом с кодом, который их использует.

То же подключение SQLite также служит основой для специализированных таблиц. Stanchion
добавляет виртуальные таблицы с колонками для аналитического чтения; `sqlite-vec` добавляет векторные таблицы и запросы расстояния. Обычные таблицы и эти расширения могут совместно использовать базу данных и участвовать в одном рабочем процессе приложения.

Эта обёртка представляет собой нативную границу SQLite: она предоставляет библиотеку и
механизм загрузки расширений, используемые реализацией хранилища более высокого уровня.
