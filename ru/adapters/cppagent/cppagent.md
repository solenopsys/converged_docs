# MTConnect CppAgent

Эта оболочка запускает агент MTConnect на C++ для Converged. Агент получает
сигналы от настроенных адаптеров станков и публикует их в виде потока данных
MTConnect. Он предоставляет станкам с ЧПУ, роботам, датчикам и другим
устройствам производственного цеха общую модель, которую может использовать
остальная часть платформы.

Оболочка запускает `cppagent` с файлом `agent.cfg`, ожидает готовности его HTTP-конечной точки
и останавливает процесс при освобождении сервиса. XML-файл устройства
описывает модель оборудования; конфигурация агента выбирает адаптеры,
порты и параметры выполнения. Клиенты считывают полученные конечные точки `/probe`, `/current`
и `/sample` из работающего агента.

Интеграция намеренно основана на отдельных процессах. Она использует встроенные
конфигурацию и HTTP-интерфейс агента, а не встраивает его библиотеку C++ в
среду выполнения Zig.
