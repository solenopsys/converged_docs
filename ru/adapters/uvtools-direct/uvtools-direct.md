# Адаптер UVtools direct

Адаптер UVtools подготавливает файлы для принтеров, работающих с фотополимерной смолой. Он запускает `UVtoolsCmd`
для обработки нарезанных файлов, позволяя проверять слои, валидировать файл, исправлять его,
конвертировать между поддерживаемыми форматами, извлекать миниатюры, а также сообщать
свойства файла или обнаруженные проблемы. Эта работа выполняется до передачи файла
адаптеру принтера.

Обёртка оставляет UVtools внешним исполняемым файлом. Её API предоставляет как путь к необработанным
аргументам, так и именованные операции для конвертации, проверки,
сравнения, извлечения миниатюр и формирования отчётов о проблемах. Она возвращает вызывающей
стороне стандартный вывод дочернего процесса, стандартный поток ошибок, код завершения
и состояние адаптера.

Сам UVtools должен быть установлен на хосте. Обёртка предоставляет границу
процесса: тайм-аут команды, рабочий каталог, ограничения на объём вывода и захват
результата.
