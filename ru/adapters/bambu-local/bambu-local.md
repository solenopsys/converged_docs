# Локальный адаптер Bambu Lab

Локальный адаптер Bambu позволяет Converged работать с принтером Bambu Lab через его
интерфейс локальной сети. Он подключается к конечной точке принтера MQTT-over-TLS,
аутентифицируется с помощью кода доступа к локальной сети и обращается к устройству по
серийному номеру. Управление печатью и телеметрия остаются в локальной сети; Bambu Cloud
не участвует в этом процессе.

Адаптер публикует команды для приостановки, возобновления и остановки печати, а также
для отправки необработанного JSON и G-кода. Он подписывается на отчёты устройства и
через обратные вызовы передаёт последнее состояние, информацию о принтере, ошибки и
телеметрию печати. Вызывающие стороны также могут запросить снимок в формате JSON,
если им требуется текущее состояние синхронно.

Подключение по умолчанию принимает самоподписанный сертификат, который обычно
предоставляют принтеры в режиме локальной сети. Расширенный API подключения принимает
сертификат центра сертификации, если требуется проверка сертификата.
