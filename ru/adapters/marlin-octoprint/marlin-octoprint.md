# Последовательный адаптер Marlin

Адаптер Marlin обеспечивает прямое последовательное соединение между Converged и FDM-принтером,
работающим под управлением прошивки Marlin. Он открывает последовательный порт принтера, отправляет
G-код и отслеживает детали протокола, которые делают поток печати надёжным: номера строк,
контрольные суммы, ответы `ok` и запросы на повторную отправку.

API охватывает управление заданиями, перемещение и позиционирование, нагреватели, экструзию,
операции с SD-картой, аварийную остановку и необработанный G-код. Ответы прошивки разбираются
в состояние принтера: температуры, координаты, идентификатор, прогресс работы с SD-картой и
статус печати. Благодаря этому слой оборудования может использовать единую модель состояния,
пока адаптер продолжает взаимодействовать с последовательным протоколом прошивки.

Название сохранено для совместимости с окружающим API. Обёртка не запускает OctoPrint и не
вызывает его HTTP API; она напрямую взаимодействует с Marlin.
