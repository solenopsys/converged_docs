## KI-Schicht

KI in Converged ist kein Zusatzmodul und keine separate Chat-Oberfläche. **LLM ist die primäre Schnittstelle zur Plattform.** Statt zu lernen, wie Dutzende komplexer Funktionen verwendet werden, und sich durch Menüebenen zu bewegen, können Benutzer im Chat einfach beschreiben, was sie benötigen — eine Frage stellen, einen Befehl geben oder eine Aktion anfordern.

Converged wurde von Anfang an als **AI-First-Plattform** entwickelt. Architektur, Datenmodell, Dienste, Workflows und UI sind auf eine natürliche Zusammenarbeit mit KI ausgelegt. Dadurch wird die Benutzeroberfläche einfacher: Benutzer müssen die interne Struktur des Systems nicht lernen, um seine Funktionen zu nutzen. Sie können mit der Plattform so interagieren, wie sie mit einer Person kommunizieren.

Gleichzeitig ist LLM mehr als eine dialogorientierte Schnittstelle. Es ist eine intelligente Steuerschicht über den Daten, Schnittstellen und Prozessen der Plattform. Ein Benutzer kann fragen, was mit einer Bestellung geschieht, eine Kundenantwort anfordern, die Ursache einer Verzögerung finden, einen erlaubten Workflow starten oder eine Zusammenfassung der Maschinenlast erhalten.

Das Modell erhält Kontext direkt aus der Plattform: Anfragen, Status, Dateien, Telemetrie, Kundenhistorie, Zugriffsrechte und aktuelle Aufgaben. Antworten und Aktionen basieren daher auf den tatsächlichen Daten des Unternehmens und nicht auf allgemeinem Modellwissen. Wenn eine Aktion erforderlich ist, umgeht die KI das System nicht — sie verwendet erlaubte Funktionen, Dienste und Workflows über eine kontrollierte Schicht.

Modelle werden über Adapter angebunden, sodass Converged nicht an einen einzelnen KI-Anbieter gebunden ist. Eine einzelne Installation kann je nach Aufgabe und Unternehmensrichtlinie GPT, Claude, DeepSeek, Mistral,Muse, Gemini oder andere Modelle verwenden. Verschiedene Modelle können unterschiedliche Rollen übernehmen: Kundenkommunikation, Interpretation technischer Anforderungen, Dokumentenverarbeitung oder Analyse von Produktionsdaten.

Das zentrale Prinzip ist **kontrollierte Intelligenz**. KI verfügt über ein eigenes Zugriffsprofil, jede Aktion wird protokolliert und kritische Vorgänge folgen denselben Berechtigungen und Richtlinien wie menschliche Aktionen. So kann KI Routinearbeit übernehmen, während Menschen und Plattform die Kontrolle über wichtige Entscheidungen und Produktionsabläufe behalten.
