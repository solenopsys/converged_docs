## Licencia

Converged se distribuye íntegramente bajo **AGPL-3.0**. Todo el código fuente de la plataforma, incluidos los Servicios, las Superficies, los Flujos de trabajo y otros módulos, es abierto y está disponible para su inspección, uso y modificación conforme a los términos de la licencia.

La plataforma tiene tres niveles: **Free, Pro y Business**. Estos niveles no dividen el código en partes abiertas y cerradas: **todos los niveles siguen siendo de código abierto**. La diferencia está en qué capacidades y módulos están disponibles para cada tipo de usuario.

* **Free** — el conjunto básico de capacidades, disponible para todos.
* **Pro** — un conjunto ampliado de capacidades para clientes **Club**.
* **Business** — capacidades profesionales y empresariales para clientes **Enterprise**.

Los niveles de pago no convierten ninguna parte de la plataforma en software de código cerrado. Las capacidades adicionales siguen siendo de código abierto, pero se distribuyen como parte del nivel correspondiente de la plataforma y están destinadas al tipo de cliente respectivo.

En un despliegue **autogestionado**, los usuarios pueden ejecutar el nivel de Converged que tengan disponible y conservar el control sobre su infraestructura, datos, actualizaciones y operaciones.

El modelo comercial de Converged no se basa en vender software cerrado. Se basa en **infraestructura, un entorno listo para usar, soporte, actualizaciones, implementación y acceso a las capacidades proporcionadas en cada nivel**.

Este enfoque conserva la principal ventaja del código abierto: el código sigue siendo transparente, inspeccionable y accesible para la comunidad, mientras que el modelo comercial define el nivel de servicio y las capacidades proporcionadas a cada tipo de cliente.
