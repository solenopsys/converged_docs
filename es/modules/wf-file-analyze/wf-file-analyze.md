# wf-file-analyze

## Propósito

Analiza un archivo almacenado que no sea un archivo comprimido y produce vistas previas del modelo y estimaciones para CNC o impresión 3D cuando es compatible.

## Límite de responsabilidad

El límite del módulo está definido por sus contratos públicos y su directorio de implementación.

- Ninguna

## Pertenencia a la solución
